# Agent rules for Indy-init

- **Tooling is F# only** ([OD-INDY-14](docs/OWNER-DECISIONS-2026-11-01.md)). Write new tooling, checks, generators and scripts in F# (`.fs`, `.fsx`, `.fsproj`). Do not add Python, shell or any other scripting language. The offline suite (`dotnet run --project tools/requirements-compiler/tests -- --offline --source .`) fails on a non-F# script under `tools/` or `.github/`; the only exceptions are the tools still to be ported, listed in that decision. Port one of them only as its own reviewed change.
- **The requirements baseline is generated by `requirements-compiler baseline . <commit>`** ([OD-INDY-15](docs/OWNER-DECISIONS-2026-11-01.md)), never edited by hand.
- **Agents never write, edit or transcribe approval records** (`kickoff/*/approvals.causa.json`) and never self-ratify (RDP-003). The owner records decisions with `tools/owner-freeze.fsx`.
- **AG-13 ("the owner's approving review of the freeze pull request") is met by the owner's package approval record** ([OD-INDY-17](docs/OWNER-DECISIONS-2026-11-01.md)): APR-V4-OWNER-3 for v4, APR-V41-OWNER-4 for v4.1. GitHub does not allow the owner to approve their own pull request. Apply it this way at kickoff (T01) and at acceptance; the tag, main and plan-digest conditions are unchanged.
- **Frozen packages are never edited.** `requirements-compiled/v4` is frozen at tag `indy-init-requirements-v4.0.0`, and CI checks it equals the tagged copy.
