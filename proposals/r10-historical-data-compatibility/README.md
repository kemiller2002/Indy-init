# R10 historical data compatibility

This is a proposal: nothing in it is merged, frozen or approved. It resolves the incompatibility between Causa's frozen v4.1.4 investigation event contracts and the historical investigations actually stored in `kemiller2002/causa-data`: Apollo 1, Apollo 11 and Challenger STS-51-L.

**Start with `FINAL-REPORT.md`.**

## Results

| Level | Meaning | Result |
|---|---|---|
| **A** | historical JSON readable | **Achieved** for all 3 cases: 1,315 lines, every file framed and canonical |
| **B** | every event decoded, typed or as an explicit lossless unsupported result | **Achieved.** 1,315 / 1,315 decode to typed events: 26 of the 31 registered types in the history, and all 31 including the synthetic fixtures. Every typed event re-encodes to its stored line byte for byte. |
| **C-projection** | the CONTRACT §8.3 fold reproduces the engine's recorded state | **Achieved.** `snapshot.json` is reproduced byte for byte. The state digest equals the catalog's for all 3 cases, and for the 4-case active catalog. |
| **C** | authoritative reconstruction | **Not achieved, and not claimed.** Admissibility (`History.validate`, CONTRACT §11.3) is not evaluated: 31 of the 35 engine-refused negative fixtures pass every check this adapter has. The frozen `CoreEvent` cannot represent 487 of the 1,315 events. |

## Reproduce

These commands need .NET SDK 10.0.402, pinned by Indy-init's `global.json`.

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone https://github.com/kemiller2002/causa-data /tmp/causa-data
git -C /tmp/causa-data checkout e8259df74add723765c57a5b1a5888d9c3f707af   # the pinned commit (source-pin.json)

cd proposals/r10-historical-data-compatibility
dotnet build tests -c Release
dotnet run --project tests -c Release --no-build -- --causa-data /tmp/causa-data
```

- **Without `--write`**, the runner regenerates both JSON reports in memory. It exits non-zero if any check fails, or if the committed reports differ from the regenerated ones.
- **With `--write`**, it rewrites the two reports. Review the diff afterwards.
- **A different causa-data commit** fails check C00 (`source-pin.json`) on purpose.

## Isolation

- **Files changed:** everything is under `proposals/r10-historical-data-compatibility/`, and no other file in Indy-init is modified.
- **Build isolation:** the proposal has its own `Directory.Build.props`, so it imports no repository build settings.
- **Other agents' files are not touched:** `docs/rehearsal-010-optimization/`, `proposals/r10-contract-first-ui/`, `tools/r10/`, frozen packages, locks, kickoff manifests and reports.
- **causa-data is read-only:** nothing was written there.
- **Language rule:** no Python or shell script is added; the work is F# only (OD-INDY-14).
