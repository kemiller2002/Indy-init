## Decisions owned elsewhere that this proposal depends on

These are not asked again here; their outcome decides Layer C:
- **ODR-R10-25** (critical, PR #119): the frozen contracts cannot represent causa-data (C1, C3, S1, S2). Without it, no backend can supply the investigation list or workspace content from real data. `real-adapter-sketch` returns `listGap` and `contentGap` for exactly these reasons.
- **ODR-R10-26**: content fields with no wire form (INV-023, INV-025, INV-027, the INV-031 options, edit events). The contracts carry them as optional values (`EvidenceCard.Label: string option`, `KindShown.UninterpretedKind`), so screens can be built either way.
- **ODR-R10-20/-21**: v4.1.5 ownership and splits. FILE-OWNERSHIP.json is written against the successor slice ids of PR #119, so one v4.1.5 cycle can adopt both.
- **ODR-R10-22**: speculative verification. It is the precondition for more UI agents to pay off.
- **S8** (J1-02 New investigation on a read-only connection): the contracts expose `NewInvestigation: Availability`, so either answer is a projection change.
