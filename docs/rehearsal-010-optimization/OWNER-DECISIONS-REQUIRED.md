# Rehearsal 010 optimization: owner decisions required

These are **prepared, not recorded**, and on purpose they are **not** in `kickoff/rehearsal-010/proposals/owner-decision-requests.json`. That file is pinned by the proposed lock (LP-03), so adding a request would change a pinned digest and the questions `decide rehearsal-010` asks. None of these is needed to launch Rehearsal 010 on the current approved plan. Each changes what is built, how it is integrated, or how long set-up is planned to take, so only the owner can adopt it. To adopt one, its request is added to the requests file in an agent PR, and the owner records it with `owner-freeze.fsx decide rehearsal-010`.
