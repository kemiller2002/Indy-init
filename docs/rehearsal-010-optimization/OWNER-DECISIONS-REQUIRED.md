# Rehearsal 010 optimization: owner decisions required

These are **prepared, not recorded**, and on purpose they are **not** in `kickoff/rehearsal-010/proposals/owner-decision-requests.json`. That file is pinned by the proposed lock (LP-03), so adding a request would change a pinned digest and the questions `decide rehearsal-010` asks. None of ODR-R10-19..24 or -27 is needed to launch Rehearsal 010 on the current approved plan. **ODR-R10-25, -26 and -28 are different:** without them, requirements in the approved scope (EXT-DATA-013, T25, the M2 journeys, PF-015-O2/O3) cannot pass against the real data repository, so a launch without them must declare those as expected failures in advance. Each changes what is built, how it is integrated, or how long set-up is planned to take, so only the owner can adopt it. To adopt one, its request is added to the requests file in an agent PR, and the owner records it with `owner-freeze.fsx decide rehearsal-010`.
