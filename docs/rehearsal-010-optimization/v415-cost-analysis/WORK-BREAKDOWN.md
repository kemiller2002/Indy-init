# v4.1.5 work breakdown

Each item below states:

- **agent-min:** agent working minutes.
- **elapsed:** wall-clock time, including CI and review waits, but not owner waits, which are listed separately in `SCHEDULE-COMPARISON.md`.
- what exists, what remains, dependencies, whether the item can run in parallel, any owner decision, whether it is on the critical path (CP), and the evidence.

All durations are **estimates**, given as ranges, unless marked *measured*. Measurements are in `COMPILATION-BOTTLENECKS.md` §1. The ranges extrapolate from:

- this session: the historical decoder, 20 checks and 12 documents took about 1 h, *measured*;
- three earlier successors: 2–19 h elapsed, 3–5 review rounds, *measured*.

Precision finer than about 30 min is not claimed.
