# Delegated technical decisions: Causa preview

**Authority.** The owner's directive of 2026-11-05, "Accelerated Readiness and Working Application Directive", §2. Its record is **SA-01** (`proposals/r10-historical-data-compatibility/proposals/owner-decision-requests.json`). SA-01 is **requested but not yet recorded**: the owner records it with `owner-freeze.fsx decide historical-compatibility`.

**What these decisions are not.** None of them was individually reviewed by the owner. Any decision the directive reserves to the owner is listed under "Escalated" and has not been taken.

| ID | Decision | Rationale | Alternatives considered | Evidence |
|---|---|---|---|---|
| D-01 | **Governance: no validator change.** The standing authorization becomes one owner record, SA-01, made with the existing `owner-freeze.fsx decide`. The validator is not changed. | The directive's own fallback. Owner-record provenance is already enforced: committer and author must be the owner, and agent commits are refused (`owner-freeze.fsx` `signedByYou`; launch-preflight LP-05). A new validator path would need its own review cycle and could block the application. | Extend the v4.1.x validator to accept an authorization reference. Rejected: the compiler checks only that an approval string is non-blank (`V41Package.fs:1781`); the real owner-record checks live in the offline suite and launch-preflight, so a change spans three places. | `COMPILATION-BOTTLENECKS.md` §3 |
| D-02 | **The preview lives in `preview/causa/` on the session branch of Indy-init.** It is a preview, not a rehearsal or the competition build. | It is the only repository and branch this session may push to. A preview gives the owner a working application to judge. | A new repository: this session cannot create one. `indy-init-rehearsal-010`: would contaminate the official rehearsal. | `list_repos` |
| D-03 | **Superseded (F#-only constraint, 2026-11-05).** The clock is read in F# at the dispatch boundary (`DateTimeOffset.UtcNow`, millisecond UTC) and passed into the pure `Dispatch.step`. Originally: the browser clock reached the engine as a `CapabilityFact { capability: "causa.clock" }`, sent by the host before each user event. | `occurredAt` must be the decision time (CONTRACT §5). Limen 0.9.1 has no clock capability; time is a browser capability and the engine stays pure. | GitHub's `Date` header: not exposed to cross-origin JavaScript. The branch head's commit date: that is the last commit's time, not now. | Limen `dist/capabilities` (no clock) |
| D-04 | **Ship FSharp.Core untrimmed** (`PublishTrimmed=false`). | FSharp.Core produces trim warnings (IL2040/IL2104), and trimming F# risks breaking reflection at runtime. The cost is about 26 MB of WebAssembly. | Trimming with those warnings suppressed. Rejected: it would hide real warnings. | build log |
| D-05 | **The catalog is read-only, and writes go only under `workspaces/demo/<workspace>/investigations/<id>/`** in a repository the user names. One `createCommitOnBranch` per save, conditional on the head the engine read. Success is reported only after a byte-identical read-back. | CONTRACT §9.4; PERSIST-005, -006, -007; UI-006-O6. | The REST Contents API (one commit per file): violates §9.4.1. | engine tests |
| D-06 | **The token is held in engine memory only.** It is sent only in the `Authorization` header, never stored, never projected into the view, and the token field is not bound back. | No secrets in browser-delivered code or storage. | `localStorage`. Rejected. | engine test "the token never appears in the view" |
| D-07 | **Reads happen at the branch-head commit SHA.** The head read carries a cache-buster, and file reads use the raw `base64` representation. | PERSIST-005 (read the head, then files at that commit). `base64` keeps exact bytes, so encoding checks (stage 2) remain possible. | `text` responses. Rejected: invalid UTF-8 would be silently replaced. | `GitHub.fs` |
| D-08 | **New investigations use only `InvestigationStarted`, `ObservationRecorded` and `HypothesisRecorded`.** IDs are UUIDv5 in a preview namespace; the actor is `causa-preview-user` (human). Every file set goes through the full reader (stages 1–14, 16, 17) before it is sent. The UI shows "admissibility not evaluated". | These are the smallest commands that give create and edit with correct storage semantics. No admissibility engine exists (OD-HC-03), so nothing claims authority. | Writing other event kinds. Rejected: their admissibility rules are engine-private. | `Writer.fs`; engine tests |
| D-09 | **The preview is built on the causa-storage v1.0.0 contract directly**, through `Causa.HistoricalCompatibility`, not on frozen v4.1.4 `CoreEvent`. | v4.1.4 cannot represent 487 of the 1,315 historical events. The minimum v4.1.5 is not yet compiled. | Waiting for v4.1.5. Rejected: the directive puts a working application first. | `SCHEMA-DIFF.md` §2 |
| D-10 | **The browser test runs Chromium through the container proxy with `ignoreHTTPSErrors`.** | The container's egress proxy re-signs TLS. This setting applies to the test browser only; the deployed site is unaffected. | none available in this container | `tests/read-path.mjs` |

## Decisions under the F#-only constraint (owner directive, 2026-11-05)

| ID | Decision | Rationale | Evidence |
|---|---|---|---|
| D-11 | **Routing is F#** (`Routing.fs`). Hash routes (D-203) are pushed through Limen navigation effects. Back, Forward and reloaded deep links arrive as `LocationChanged`/`Initialize` and are interpreted by the engine; a browser move is never pushed again. | The constraint covers navigation and routing. | engine tests (6 routing checks); browser test (hash route, Back, deep link) |
| D-12 | **The transport is Limen's `DotnetWasmTransport`.** The application's own transport class is removed, and responses are checked by Limen's generated contract decoder. | It leaves the minimum JavaScript: 2 code lines. | `ARCHITECTURE.md` JS-1; A2 |
| D-13 | **`tests/ArchitectureCheck.fsx` (A1–A7) enforces the constraint on every run.** Mutation runs showed it fails on an extra JS file, a `fetch` in `main.js`, a branch in the C# shim, an inline handler, and an unprojected binding. | "Verify this constraint continuously through source inspection and automated architecture checks." | mutation run in this session |
